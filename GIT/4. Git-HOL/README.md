# GitDemo

## Objective
This project demonstrates the basic Git operations required for the Cognizant Digital Nurture Git Hands-on.

## Operations Performed

- Git installation and configuration
- Repository initialization
- Creating and tracking files
- Git status
- Git add
- Git commit
- GitHub remote repository setup
- Git push
- Creating and switching branches
- Comparing branches using git diff
- Merging branches
- Resolving merge conflicts
- Viewing commit history
- Deleting branches
- Using .gitignore

## Commands Used

- git init
- git status
- git add
- git commit
- git push
- git branch
- git checkout
- git merge
- git diff
- git log
- git rm
- git remote
