# Git-HOL_003 - Clean Up and Push to Remote Git

## Objective

This hands-on demonstrates how to clean up the local Git repository, synchronize it with the remote repository, and verify that all changes are successfully pushed to GitHub.

## Prerequisites

- Completion of Git-HOL_002
- Git installed and configured
- GitHub repository created

## Tasks Performed

- Verified that the repository was in a clean state.
- Listed all available branches.
- Pulled the latest changes from the remote repository.
- Pushed local commits to the remote repository.
- Verified that all files were successfully updated on GitHub.

## Git Commands Used

```bash
git status
git branch -a
git pull origin main
git push origin main
```

## Expected Outcome

- Working tree is clean.
- Local repository is synchronized with the remote repository.
- Latest commits are successfully pushed to GitHub.
- Repository is updated with all project files.
