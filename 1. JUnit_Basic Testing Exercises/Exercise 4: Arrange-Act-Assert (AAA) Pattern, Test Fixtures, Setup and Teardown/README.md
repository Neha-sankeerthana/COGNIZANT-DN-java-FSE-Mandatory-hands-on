# JUnit Basic Testing Exercises – Exercise 4: Arrange-Act-Assert (AAA) Pattern, Test Fixtures, Setup and Teardown

## Overview

This exercise demonstrates the Arrange-Act-Assert (AAA) testing pattern along with the use of JUnit test fixtures using the `@Before` and `@After` annotations.

It is part of the Cognizant Digital Nurture 4.0 – Java FSE Deep Skilling Program.

## Objective

- Organize test cases using the Arrange-Act-Assert (AAA) pattern.
- Initialize test resources before each test.
- Release resources after each test.
- Execute unit tests successfully.

- Java 22
- IntelliJ IDEA
- Maven
- JUnit 4.13.2

## Features Implemented

- AAA (Arrange-Act-Assert) testing pattern
- `@Before` annotation for test setup
