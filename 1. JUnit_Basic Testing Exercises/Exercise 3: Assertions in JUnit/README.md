# JUnit Basic Testing Exercises – Exercise 3: Assertions in JUnit

## Overview

This project demonstrates the use of different JUnit assertions to validate test results. Assertions are used to verify whether the expected output matches the actual output, ensuring the correctness of the program.

## Assertions Implemented

The following JUnit assertions were used in this exercise:

- `assertEquals()` – Verifies that the expected value matches the actual value.
- `assertTrue()` – Verifies that a given condition is true.
- `assertFalse()` – Verifies that a given condition is false.
- `assertNull()` – Verifies that the object reference is null.
- `assertNotNull()` – Verifies that the object reference is not null.

## Test Description

The test method validates the following conditions:

- Equality of two values.
- A true boolean condition.
- A false boolean condition.
- A null object reference.
- A non-null object reference.
